# Project Vitamin Dee Website — Version 3

## Upload structure

Upload everything inside this folder to the root of your existing GitHub repository:

```
project-vitamin-dee/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── coach-dee-hero.jpg
    └── project-vitamin-dee-logo.png
```

Keep GitHub Pages configured as:

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

## Before public promotion

1. Replace the two `href="#"` placeholder contact links in `index.html` with your real Messenger, Instagram, booking-form, or email links.
2. Replace the sample Stories of Sunshine text with approved testimonials.
3. Connect the Sunshine Letter form in a future update; it currently does not submit anywhere.

## Publishing

After uploading and committing the files, wait 1–3 minutes. Then open:

https://receiveyoursunshine.github.io/project-vitamin-dee/

Use a hard refresh if needed:

- Mac: Command + Shift + R
- Windows: Ctrl + Shift + R

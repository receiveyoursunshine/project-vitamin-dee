# Project Vitamin Dee Website V2

A custom, responsive static website for Project Vitamin Dee.

## Files

- `index.html`
- `style.css`
- `script.js`
- `assets/coach-dee-hero.jpg`
- `assets/project-vitamin-dee-logo.png`

## Publish on GitHub Pages

Upload all files and the `assets` folder to the root of your existing repository.

Your repository should look like:

```text
project-vitamin-dee/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── coach-dee-hero.jpg
    └── project-vitamin-dee-logo.png
```

GitHub Pages should remain configured as:

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

## Important personalization

Search `index.html` for:

```html
data-placeholder-link
```

Replace the corresponding `href="#"` values with your real Messenger, Instagram, booking form, or email links.

Replace the sample testimonials with approved client feedback before publicly promoting the site.

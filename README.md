# Project Vitamin Dee Website

A free, responsive one-page starter website for Project Vitamin Dee.

## Files

- `index.html` — website content
- `style.css` — colors, layout, typography, and mobile design
- `script.js` — mobile menu and small interactions

## Personalize before publishing

1. Replace the portrait placeholder with your actual photo.
2. Replace sample coaching packages with your final offers.
3. Replace sample testimonials with approved client feedback.
4. Search `index.html` for `EDIT:` and replace `#` with your actual links.
5. Update social links, booking form, and contact details.
6. Review the coaching disclaimer in the footer.

### Adding your portrait

Put your photo inside this folder, for example `coach-dee.jpg`.

Then replace this block in `index.html`:

```html
<div class="portrait-placeholder">
  ...
</div>
```

with:

```html
<img class="portrait-placeholder" src="coach-dee.jpg" alt="Coach Dee of Project Vitamin Dee">
```

## Publish free using GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository named `project-vitamin-dee`.
3. Upload `index.html`, `style.css`, `script.js`, and your images.
4. Open the repository's **Settings**.
5. Select **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/root`, then save.
8. GitHub will display your live website address.

Your free address will normally look like:

`https://YOUR-USERNAME.github.io/project-vitamin-dee/`

## Alternative: Canva

You can recreate this as a one-page Canva Website and publish it to a free Canva domain. Canva is simpler to edit visually, while this GitHub version gives you more freedom and avoids website-builder branding.
